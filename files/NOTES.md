## Novidades da versão 1.7.5

- **Quem usa o WaveSynk?**: nova seção na tela inicial com os canais VOIDWEST, SYNKRYPT e ELETTRO. Clique num cartão para abrir o canal no YouTube.
- **Agora também no Android**: primeira versão do WaveSynk para celular e tablet, com o mesmo editor, efeitos, visualizadores e exportação. Importa da galeria e salva/compartilha o vídeo exportado.

### Downloads
- **WaveSynk-Setup-1.7.5.exe**: instalador para Windows (recomendado). Atualiza sozinho nas próximas versões.
- **WaveSynk-1.7.5-portatil.exe**: versão portátil para Windows, roda sem instalar (não se atualiza sozinha).
- **WaveSynk-1.7.5-android.apk**: versão para Android. Baixe no celular, toque no arquivo e permita a instalação (fontes desconhecidas). Para atualizar, instale o APK novo por cima.
